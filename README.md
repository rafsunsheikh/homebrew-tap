# rafsunsheikh/tap

Homebrew formulae for the terminal apps listed in [TUI_study](https://github.com/rafsunsheikh/TUI_study).

```bash
brew install rafsunsheikh/tap/vizdesk
```

| Formula | What it is |
|---|---|
| [vizdesk](https://github.com/rafsunsheikh/vizdesk) | Scans CSV and Excel files, suggests cleaning and charts by rules (no LLM), and draws PNG figures. |

Each formula installs the app from PyPI into its own private Python environment, so it does not touch your other Python packages.
